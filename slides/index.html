Building a Focus Log
with Tiger Data

A student habit database.

Focus Log

When do you actually focus?

Log the hour, the place, and how each session went.

Time series

Each row says what happened, and when.

A study session. An API request. A sensor reading. Group them by hour or day.

What you’ll find

The best hour. The best place.

A month of rows also shows what changed the week before a deadline.

Why Tiger Data

  • The data lives in the same place.A session, a student, and a course join with normal SQL.
  • The month is split by time for you.You still query it like a normal table.
  • Daily totals stay up to date.A screen can read the summary instead of every session.
  • It is still PostgreSQL.Same SQL, same drivers, same tools.

Three things we’ll use

  • HypertableThe sessions table, split by time for you.
  • Time bucketGroup sessions into an hour or a day.
  • Continuous aggregateDaily totals the database keeps up to date.

The queries are normal SQL.
