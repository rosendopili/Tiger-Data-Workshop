Building a Focus Log
with Tiger Data

Focus Log

Find when you focus best.

Log the hour, the place, and how each session went.

Time series

Each row has a timestamp.

It records what happened and when, so you can group those rows by hour or day.

What you learn

See the best hour and place.

A month of sessions also shows the week before a deadline.

Why Tiger Data

  • The log lives with the rest of the app.Sessions, students, and courses join with normal SQL.
  • The month is split by time for you.You still query it like a normal table.
  • Daily totals stay up to date.A dashboard can read the summary instead of every session.
  • It is still PostgreSQL.Same SQL, same drivers, same tools.

Three things we'll use

  • HypertableThe sessions table, split by time for you.
  • Time bucketGroup those sessions into an hour or a day.
  • Continuous aggregateDaily totals the database keeps up to date.
